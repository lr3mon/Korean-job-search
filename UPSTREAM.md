# Upstream provenance

Korean-job-search derives its career-profile → posting evaluation → drafter/reviewer → application history/interview workflow from [MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search), reviewed at `120f476a089358363ceaf2528f52edf2854994bd` (2026-09-21).

Upstream is MIT © 2026 Mads Lorentzen. The notice and license are retained in LICENSE. This is an independent Korean-market adaptation, not an official upstream product or a product affiliated with any named model provider or employer.

What is reworked: Korean question-based applications, evidence/story records, role-specific reflection, exact character/byte limits, first-party Korean recruiting sources, portable Agent Skills, runtime-free deterministic Python helpers, and private workspace separation. No upstream personal profile was imported. Danish search adapters and mandatory LaTeX are deliberately not shipped.

Career portal content retains its original ownership; only bounded public metadata/evidence is referenced. The curated employer directory is not a financial top-100 ranking. See data/research/selection.json for scope.
