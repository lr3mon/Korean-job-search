# 지원서 검토·사용자 인계 템플릿

실제 내용은 `workspace/` 사본에만 작성한다. 빈 필드는 미확인이다.

- 회사 / 법인 / 직무 / 공고 ID:
- 현재 공고 URL / 확인 시각:
- 마감 원문 / KST 표기 / 시간 정밀도:
- 문항 출처 / 확인 시각 / 회차 일치 여부:
- 기준 초안 버전 / 검토본 버전:
- 검토 방식: 독립 검토 / 동일 에이전트 2차 검토 / 사용자 검토 중 실제 해당 값:
- 자격·중복 지원·일정 충돌:

## 문항별 검증

| 번호 | 현재 문항 원문 | 답변 파일 | 실제 길이 | 제한·모드·공백·줄바꿈 | 근거 경험 | 미확인 |
|---|---|---|---|---|---|---|

## 발견 사항

| 심각도(차단/수정 권고/선택 개선) | 현재 문구 | 이유 | 근거 | 최소 수정안 | 확인자·결과 |
|---|---|---|---|---|---|

## 인계 전 확인

- [ ] 이름·도구·수치·날짜와 책임 범위를 증거와 대조했다.
- [ ] 개인 기여와 팀·회사 결과를 분리했다.
- [ ] 판단 → 행동 → 결과 → 성찰이 실제 경험 범위를 넘지 않는다.
- [ ] 질문의 하위 요구와 현재 제한을 모두 확인했다.
- [ ] 수정 후 답변 파일에서 분량을 다시 계산했다.
- [ ] 블라인드 금지 정보·첨부·속성·링크를 확인했다.
- [ ] 수정하지 않은 문항이 이전 버전으로 되돌아가지 않았다.

## 실제 상태와 남은 일

- 로컬 초안/검토 상태와 산출물:
- 온라인 입력/저장: 수행하지 않음 / 별도 승인된 실제 확인 상태:
- 동의/최종 제출: 수행하지 않음 / 지원자가 완료한 직접 증거:
- 차단·충돌·사용자 확인 필요:
- 다음 행동과 담당자:

확인하지 않은 항목에 체크하지 않는다. 접수 증거 없는 제출 완료, 등록 증거 없는 알림 완료를 기록하지 않는다.
