## 초안(아직 작성하지 않음)

질문이 확인되면 근거가 있는 사실만 사용해 작성하세요.
성과 문항은 STARR(상황·과제·행동·결과·Reflection), 짧은 이력서 항목은
PAR(문제·행동·결과)을 참고하되 질문에 맞게 고르세요. 최종 본문에 틀 이름을
기계적으로 붙이지 마세요. Reflection은 이후 바뀐 구체적 행동으로 쓰세요.
회사 내부 문제나 경험·성과를 상상해서 빈칸과 글자 수를 채우지 마세요.

- 글자 수 검사 결과 / 기준 / 실행 시각:
- 원문 질문에 직접 답하는가:
- 근거 없는 수치·날짜·역할·인과는 없는가:
- 개인 기여와 팀·회사 성과가 구분되는가:
- 이름·회사명·도구명·기간·격식이 일관되는가:
- 최종 검토자 / 확인 시각 / 제출 승인: 미승인

검사 통과는 합격 가능성이나 내용의 사실성을 보증하지 않습니다.
자동 제출하지 마세요. 사람이 원문 양식·글자 수·개인정보 공개 범위를 확인하고
명시적으로 승인한 뒤 직접 제출해야 합니다.
